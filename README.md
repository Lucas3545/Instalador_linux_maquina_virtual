Instalador Linux para Máquina Virtual
Repositorio que reúne imágenes ISO, manuales de estudio y guías de comandos para instalar y practicar con distribuciones Linux dentro de máquinas virtuales.

📦 Contenido del repositorio
Este repositorio incluye materiales esenciales para aprender, instalar y administrar sistemas Linux en entornos virtualizados:

🖥️ Imágenes ISO
Archivos ISO necesarios para instalar distribuciones Linux en una máquina virtual (VirtualBox, VMware, Hyper‑V, etc.).

Coloca aquí las ISO cuando las subas, o describe las distribuciones disponibles.

📚 Manuales y guías disponibles
Guia_Comandos_Linux_Ubuntu.pdf  
Introducción a comandos básicos y esenciales para trabajar en Ubuntu.

Guia_Permisos_Linux.pdf  
Explicación detallada del sistema de permisos en Linux: usuarios, grupos, chmod, chown, etc.

Manual_Comandos_kali-linux.pdf  
Comandos fundamentales para Kali Linux orientados a ciberseguridad y análisis.

Manual_Estudio_Kali_Linux.pdf  
Material de estudio para comprender herramientas y funcionamiento de Kali Linux.

Manual_Estudio_Ubuntu.pdf  
Guía de estudio para usuarios nuevos de Ubuntu y administración básica del sistema.

🎯 Objetivo del proyecto
Este repositorio está pensado para:

Estudiantes que desean practicar Linux en máquinas virtuales.

Personas que necesitan material de estudio centralizado.

Usuarios que buscan instalar distribuciones Linux de forma rápida y guiada.

Cursos o talleres que requieren recursos descargables y organizados.

🚀 Cómo usar este repositorio
Descarga la ISO de la distribución que quieras instalar.

Crea una máquina virtual en tu software preferido.

Carga la ISO como disco de instalación.

Sigue los manuales PDF incluidos para aprender comandos, permisos y administración básica.

Practica con las herramientas y ejercicios sugeridos en los documentos.
